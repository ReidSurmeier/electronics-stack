# Domain documentation

This repository uses a single domain context.

Before changing behavior:

1. Read `CONTEXT.md`.
2. Use its canonical terms in interfaces, tests, issues, and documentation.
3. Read relevant decisions under `docs/adr/`.
4. Surface conflicts with an existing decision instead of silently
   overriding it.

`CONTEXT.md` is a glossary, not an implementation specification. Record
hard-to-reverse implementation decisions as concise ADRs.
